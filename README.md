#  MedFormula

**MedFormula** é uma empresa farmacêutica especializada em **medicamentos manipulados**, focada em inovação, qualidade e segurança na produção de fórmulas personalizadas.  

Este perfil da organização no GitHub representa a **unidade de TI e Dados**, responsável por transformar dados em insights estratégicos para toda a empresa.

---

## Sobre o Time de TI / Dados

- Extraímos e processamos dados de sistemas internos e indicadores de produção e vendas.  
- Desenvolvemos pipelines de **ETL** para limpeza, transformação e integração de dados.  
- Automatizamos dashboards e relatórios em **BI**, garantindo informações precisas para decisões gerenciais.  
- Priorizamos **segurança, confiabilidade e qualidade** dos dados.
